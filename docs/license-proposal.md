# Proposed project license

The maintainer is considering MIT for Scraply's own source. This draft is **not an operative license**. Before adding a root `LICENSE` and making the repository public, the maintainer must approve the grant, confirm ownership and the copyright line, and review third-party obligations. Until then, the private repository's existing access terms apply.

Scraply's proposed project license would not replace the runtime's [Apache 2.0 license](../runtime/LICENSE), the pinned upstream license, notices bundled with the app, or other third-party terms. Review the [runtime provenance](../runtime/UPSTREAM.md) and `src/renderer/public/third-party-notices.txt` before public launch.
