# Scraply Project Instructions

## Build after changes
- After each run (any change to this project's code), run `bun run build:installed` from the project root to rebuild and update the locally installed app.
- If that command fails, report the failure clearly and include the relevant error output. Do not claim the app is updated if the build did not succeed.

## Package manager
- Use `bun` for all scripts and dependency management. Do not use npm or yarn.
